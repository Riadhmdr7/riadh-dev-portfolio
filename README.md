## Repository layout

```
projects/          one folder per project (01-name, 02-name, ...)
learning/          notes and exercises on CS and AI foundations
templates/project/ starter copied for each new project
docs/              conventions and roadmap
.github/workflows/ CI: lint and tests for every project
```

To start a new project: `cp -r templates/project projects/02-my-project`, then edit its README.
